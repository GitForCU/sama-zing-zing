# การปรับ UI ตามแบบอ้างอิง

ปรับวันที่ 26 ตุลาคม 2026 โดยอ้างอิง PDF หน้าจอ 13 หน้าที่ผู้ใช้แนบ และเชื่อมกับ API ของระบบเดิม

## หน้าจอ

| หน้าใน PDF | หน้าที่ปรับ | สิ่งที่ยึดจากต้นฉบับ |
|---|---|---|
| 1 | แดชบอร์ดห้องเรียน | กราฟวงแหวนสีชมพู/ฟ้า กล่องจำนวนคน ดาวน์โหลดสีม่วง แถบยังไม่เสร็จ/เสร็จแล้ว |
| 2 | หน้าหลักครู | ชื่อโรงเรียน บัตรต้อนรับพร้อม avatar และรายการค้างตรวจ |
| 3-4 | ตรวจและส่งคืนกิจกรรม | รายการแนวตั้ง checkbox แถบยังไม่ได้ตรวจ/ประวัติ และปุ่มส่งคืนสีแดง/อนุมัติสีเขียว |
| 5 | สถิตินักเรียน | วงแหวนพร้อม avatar กล่องสีตามสถานะ และสถิติแต่ละหมวดแบบเปิด/ปิด |
| 6 | เข้าสู่ระบบ | พื้นหลังม่วงไล่สีพีช avatar SAMA และฟอร์มสีขาว ปุ่มม่วง |
| 7 | หน้าหลักนักเรียน | บัตรต้อนรับ ปุ่มลัด กำหนดส่งสีส้ม และการ์ดกิจกรรมเลื่อนแนวนอนบนมือถือ |
| 8 | หมวดกิจกรรม | การ์ดสองคอลัมน์บนมือถือ สีไล่ระดับ วงกลมตกแต่ง และเปอร์เซ็นต์บนการ์ด |
| 9 | เพิ่มกิจกรรม | แถบชื่อหมวดสีม่วง/แดง วันที่ เวลา รายละเอียด ปุ่มร่างขอบส้มและปุ่มส่งสีส้ม |
| 10 | ดูกิจกรรม | ข้อมูลกิจกรรม ประวัติในกรอบสีฟ้า/ส้ม/เขียว และสัญลักษณ์อนุมัติ |
| 11 | รายการกิจกรรม | ตัวกรองสีตามสถานะ และรายการที่ใช้สีกรอบบอกผลตรวจ |
| 12 | บัญชีผู้ใช้ | บัตรส่วนตัวไล่สีส้ม/ฟ้า และเมนูเป็นรายการสีขาว |
| 13 | ครูที่ชื่นชอบ | ช่องค้นหา รายชื่อแนวตั้ง และดาวสีเหลือง |

## การปรับเล็กน้อยเพื่อใช้งานจริง

- ใช้ชื่อโรงเรียนตาม SRS และข้อมูลจริงจากฐานข้อมูลแทนตัวเลขตัวอย่างในภาพ
- เมนูที่ยังไม่มีฟังก์ชัน เช่น ชุมชน แทนด้วยทางเข้าครูโปรด/ห้องเรียนที่ใช้งานได้
- หน้าจอคอมเพิ่มเมนูด้านข้างและขยายจำนวนคอลัมน์ มือถือใช้แถบล่างห้าตำแหน่งพร้อมปุ่มกลาง
- เมื่อเปิดฟอร์มจากหมวดกิจกรรม ชื่อเริ่มต้นเป็นชื่อหมวดและแก้ไขได้ทันที กดส่งแล้วเลือกครูในขั้นตอนถัดไป ส่วนปุ่ม + เปิดฟอร์มที่กำหนดหมวดและชื่อเองได้ ทั้งสองทางแนบรูป/PDF ได้
- สถิติที่เป็นจำนวนรายการใช้หน่วยรายการ ไม่แปลงปนกับชั่วโมง/ครั้งเป็นเปอร์เซ็นต์ที่ทำให้เข้าใจผิด
- CSV ส่งออกทั้งเทอมและมีข้อความกำกับ แม้กำลังดูสถิติที่กรองตามหมวด
- รายการสมัครบัญชี ลบบัญชี และยกเลิกผลตรวจยังไม่เปิดเป็นปุ่มดำเนินการ เพราะยังไม่ได้กำหนด flow ครบ

## การตรวจ

TypeScript/Vite build ผ่าน และ browser tests ผ่าน 6 กรณี ตรวจการใช้งานหลักและหน้าจอที่ความกว้าง 360, 390, 768 และ 1440 px รวมทั้งการแก้ชื่อ บันทึก/เปลี่ยนหลักฐาน และให้ครูดาวน์โหลด โดยใช้ PostgreSQL แยกสำหรับการทดสอบ
